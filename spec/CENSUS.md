# The specification census

Generated by `python spec/probes/census.py --write` from `spec/census.json` (the measurement: `--measure` on the game copy) and the
rules of `spec/**/*.md`; do not edit by hand. Everything in DICE's game files (dated before 2013), each item with
the rules that name it (a rule names an item when its heading, body or evidence holds the name as a whole word;
catalogue rules that only list names - ENG-TI-3, GFILE-KIND-1, RES-TYPE-1, RES-TYPE-2, RES-TYPE-3 - do not count), or the reason it is out of scope.
`python spec/probes/census.py --check` (the quick tier) fails when a file kind, a resource type, a DBX class with at least 10
instances or a typeinfo module has neither (GFILE-KIND-1, ENG-TI-1).
