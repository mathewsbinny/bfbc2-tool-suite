# Roadmap

The suite's priorities and its queue of rounds. Everything from the GENERATED marker down is written by
`python tasks\build.py` from the task registry, `tasks/registry.toml`: the one list of every task in every
repository (round TK0, 2026-11-28; its fields and rules are in `tasks/README.md`). To change a task, edit its block in
the registry and run the generator. `python tasks\build.py --check` (the quick tier's `tasks-registry`) fails while
this file is stale.

- **A round's lane** is set in the registry: `run` when its branch starts, `merge` when it is ready. At the merge,
  `python tasks\build.py merge <code>` marks it done, adds its CHANGELOG fragment and assigns its version
  (`RELEASING.md`).
- **The priority order** changes only when the user changes it. It is the registry's `[[priority]]` groups, each
  with the ruling it comes from.
- **Where the rest lives:**
  - `CHANGELOG.md`: what users notice, version by version.
  - `rust/BENCHMARKS.md`: each round's measurements. The Done lines below link its sections.
  - `PYTHON_STATUS.md`: the Python that is left, file by file and by PX round.
  - `RELEASING.md`: how a round reaches `main` and how versions are made.
  - battlefield-opfor's `docs/tasks/TASKS.md`: the same registry, every repository's tasks on one page.
