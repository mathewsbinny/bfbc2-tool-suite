A badge names a fixed property at a glance: the content profile, a team, a flag's owner or a game mode.

- **Profile badge** (`accent` outline and text): the project's content profile (BFBC2, VIETNAM, WW2 - PACIFIC
  WAR) in the top bar. One per window.
- **Team badge**: a `team-1`, `team-2` or `team-neutral` square plus its label (US, RU, JP; FLAG A). The label is
  required; the colour alone never identifies a team.
- **Plain badge** (`surface-2`, `line-strong`): modes and other categories.

Text is short, in capitals, 11px with a little letter-spacing; corners `radius-sm`. Badges are not buttons: an
action goes on a Button.
